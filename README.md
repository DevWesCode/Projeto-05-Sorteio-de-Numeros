# 🔢 Projeto 05 - Sorteador de Números

Um aplicativo simples e direto para gerar um número aleatório dentro de um intervalo. Desenvolvido com HTML, CSS e JavaScript, o projeto proporciona uma experiência visual agradável com feedbacks dinâmicos para entradas inválidas e simulação de sorteio.

---

## 🎯 Funcionalidades

- Definição de valor mínimo e máximo.
- Geração de número aleatório dentro do intervalo definido.
- Validação de campos e mensagens de erro amigáveis.
- Efeito de "sorteio em andamento" com pequeno delay.
- Interface responsiva e moderna.

---

## 💻 Tecnologias Utilizadas

- **HTML5** — Estrutura da aplicação.
- **CSS3** — Estilização e responsividade.
- **JavaScript (ES6)** — Lógica de sorteio e manipulação do DOM.

## 📚 Aprendizados

Neste projeto, pratiquei e consolidei:

- Manipulação de eventos com `addEventListener`.
- Tratamento de inputs e validação de valores numéricos.
- Geração de números aleatórios com `Math.random()`.
- Estilização centrada em acessibilidade e responsividade.
- Uso de classes utilitárias como `.sr-only` para acessibilidade.
